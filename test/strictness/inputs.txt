# Strictness probe inputs — LOCALLY AUTHORED (this file is ours, so it is
# tracked; the zigzon corpus is third-party and is not).
#
# These target the leniency that @tabnas/zon inherits from @tabnas/jsonic.
# The plugin is a JSONIC plugin: `new Tabnas().use(Zon)` alone cannot parse
# even `.{ .a = 1 }`, so there is no stricter standalone mode to fall back to —
# jsonic's relaxed lexer and its "first value wins" top-level behaviour come
# through unconditionally.
#
# THE VERDICTS ARE NOT IN THIS FILE. scripts/fetch-zigzon.sh feeds every line
# below to the pinned Zig reference implementation (test/zigzon/tools/oracle.zig)
# and writes test/strictness/cases.json. Nothing here asserts what ZON means;
# only Zig does. That is deliberate — a probe list that also carried its own
# expected answers would just be this repo grading itself.
#
# Format: one input per line. `#` in column 1 is a comment. Escapes \n \t \\
# are decoded, so a line can carry a multi-line document.
